# Umme Amara - About portrait sticker

`portrait.jpg` is the supplied original 720 x 1280 photograph. The original file remains unchanged.
It appears only in About, outside the text box, as a 224 x 280px portrait on desktop and 184 x 230px on mobile (4:5). CSS `object-fit: cover` and `object-position: center 28%` frame the face without editing or recompressing the source. Rounded corners, a thin colorful edge, repeatable reveal, and the existing desktop tilt are retained.
